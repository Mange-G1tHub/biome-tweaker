
# Create : Biome Tweaker

This mod is a late/end game mod that will give you the ability via machines to **change the current biome** into one of your choice (from the available list), with `Create's rpm system`.

> The mod is currently in **Alpha**, so the textures, gameplay mechanics, recipes can change, some items might be removed. So it isn't recommended to add the mod into your modpack, and use it seriously.

> Recipes, textures, functionalities, translations and gameplay elements suggestions are accepted. So if you have some ideas, I'm open to review them.

## Planned functionalities/elements :

- New ore -> `Platinum` :
  - Ore that can be founded in **the End**. The pickaxe tier needed to mine the ore is **Netherite**;
  - Maybe there will be platinum tools, if so, they will be unbreakable or have a special functionality (insta-mine nearly all blocks, ability to _break Bedrock_ ?);
  - Maybe add `Impure Platinum`, an ore that can be founded in the nether, and it will permit to craft/upgrade a furnace to properly smelt the Raw Platinum, found in **the End**;
  - A `Platinum pan` that will permit the reuse of `Blaze Cake` or `Freezing cake`, without consuming the base. So, just need to refill it with a spout;
- The `Biome Tweaker` :
  - A one block (or multi-block structure) that will give the ability to change the biome;
  - For the _biome changing_ operation, maybe add a `superheated Blaze burner` to make the biome warmer, or an inverted equivalent to the Blaze burner, to freeze things and make the biome cooler;
  - Will require **max rpm speed** to run, and a **variable SU** requirement for the range of the (multi)block;
- An inverted equivalent of **Create's Blaze Burner** to cool/freeze things, instead of heating them;

> This is my first mod, fully handwritten. So please be gentle for potential errors. AI will not be used, neither for coding, textures nor this README, the objective is to be able to make a mod by myself.
